Panduan Online-kan Website via GitHub Pages

Agar bisa dibuka oleh dosen/teman dari HP mana saja

Website ini berbentuk single-file index.html. Ikuti petunjuk berikut untuk mempublikasikannya secara gratis.
  1. Buat Akun GitHub: Jika belum punya, buat akun gratis di github.com.
  2. Buat Repository Baru:
    • Klik tombol **"+"** di pojok kanan atas -> pilih **New repository**.
    • Isi Repository name, contoh: dashboard-perkuliahan.
    • Pastikan memilih opsi **Public**.
    • Klik tombol **Create repository**.
  3. Upload File index.html:
    • Di halaman repository, klik link **"uploading an existing file"**.
    • Simpan kode file ini di komputer/HP Anda dengan nama persis index.html.
    • Drag & drop atau unggah file index.html tersebut.
    • Klik tombol **Commit changes**.
  4. Aktifkan GitHub Pages:
    • Masuk ke menu **Settings** di baris atas repository.
    • Klik tab **Pages** di menu bagian kiri.
    • Pada bagian *Build and deployment* -> *Branch*, ubah dari **None** ke **main** (atau **master**).
    • Klik **Save**.
  5. Selesai! Link Website Publik Anda:

    Tunggu 1-2 menit, lalu website Anda dapat diakses di link berikut:

    https://[username-github-anda].github.io/dashboard-perkuliahan/
